# Report fonts

These fonts are bundled so report rendering never needs system fonts or a network.
All are licensed under the SIL Open Font License 1.1; the accompanying license files
retain the upstream notices. `provenance.json` records immutable source revisions,
asset SHA-256 hashes, and the two static-weight conversions. The static instances
retain the full font coverage; the PDF renderer embeds only glyphs used by a report.
No font conversion tool is needed to build or run the application.
